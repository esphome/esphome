# LILYGO T5 4.7" Plus E-Paper Display

This component provides support for the ESP32-S3 based LILYGO T5 4.7" Plus E-Paper Display.

## Hardware

- **Display**: 4.7" E-Paper (960x540 pixels)
- **MCU**: ESP32-S3
- **Interface**: I2S parallel interface
- **Features**: Grayscale support, touch interface
