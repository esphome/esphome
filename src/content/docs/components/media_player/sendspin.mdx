The `sendspin` media player platform exposes controls for an entire [Sendspin](/components/sendspin/) group as a Home Assistant media player entity.

> [!IMPORTANT]
> This platform does not produce any audio on the device. It only sends playback and volume commands to the Sendspin server, which applies them to every player in the active group. Commands like play/pause, volume, mute, shuffle, repeat, and next/previous track are forwarded to the group as a whole.

The Sendspin [hub](/components/sendspin/) must be configured on the same device. This platform only works on ESP32-based chips using the [ESP-IDF framework](/components/esp32#esp32-framework).

```yaml
# Example configuration entry
sendspin:

media_player:
  - platform: sendspin
    name: "Sendspin Group"
```

## Configuration variables

- **volume_increment** (*Optional*, percentage): The amount that the
  [`media_player.volume_up`](/components/media_player#media_player-volume_up)
  and [`media_player.volume_down`](/components/media_player#media_player-volume_down)
  actions change the group volume by. Defaults to `5%`.
- All other options from [Media Player](/components/media_player#config-media_player).

## Supported actions

The following standard [Media Player actions](/components/media_player#media_player-actions) are forwarded to the Sendspin group:

- [`media_player.play`](/components/media_player#media_player-play),
  [`media_player.pause`](/components/media_player#media_player-pause),
  [`media_player.stop`](/components/media_player#media_player-stop),
  [`media_player.toggle`](/components/media_player#media_player-toggle)
- [`media_player.volume_set`](/components/media_player#media_player-volume_set),
  [`media_player.volume_up`](/components/media_player#media_player-volume_up),
  [`media_player.volume_down`](/components/media_player#media_player-volume_down)
- [`media_player.mute`](/components/media_player#media_player-mute),
  [`media_player.unmute`](/components/media_player#media_player-unmute)
- [`media_player.next`](/components/media_player#media_player-next),
  [`media_player.previous`](/components/media_player#media_player-previous)
- [`media_player.shuffle`](/components/media_player#media_player-shuffle),
  [`media_player.unshuffle`](/components/media_player#media_player-unshuffle)
- [`media_player.repeat_off`](/components/media_player#media_player-repeat_off),
  [`media_player.repeat_one`](/components/media_player#media_player-repeat_one),
  [`media_player.repeat_all`](/components/media_player#media_player-repeat_all)

Playing arbitrary media and announcements are not supported.
