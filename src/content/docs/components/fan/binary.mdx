The `binary` fan platform lets you represent any binary [Output Component](/components/output/) as a fan.

<Image src={fanUiImg} layout="constrained" alt="" />

```yaml
# Example configuration entry
fan:
  - platform: binary
    output: fan_output
    name: "Living Room Fan"
```

## Configuration variables

- **output** (**Required**, [ID](/guides/configuration-types#id)): The id of the
  binary output component to use for this fan.

- **oscillation_output** (*Optional*, [ID](/guides/configuration-types#id)): The id of the
  [output](/components/output/) to use for the oscillation state of this fan. Default is empty.

- **direction_output** (*Optional*, [ID](/guides/configuration-types#id)): The id of the
  [output](/components/output/) to use for the direction state of the fan. Default is empty.

- All other options from [Fan Component](/components/fan#config-fan).
