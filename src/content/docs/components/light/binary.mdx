The `binary` light platform creates a simple ON/OFF-only light from a
[binary output component](/components/output/).

<Image src={binaryUiImg} layout="constrained" alt="" />

```yaml
# Example configuration entry
light:
  - platform: binary
    name: "Desk Lamp"
    output: light_output
```

## Configuration variables

- **output** (**Required**, [ID](/guides/configuration-types#id)): The id of the binary [Output Component](/components/output/) to use for this light.
- All other options from [Light](/components/light#config-light).
