The `safe_mode` switch allows you to remotely reboot your node into [Safe Mode](/components/safe_mode/). This is useful in certain situations where a misbehaving component, or low memory state is preventing Over-The-Air updates from completing successfully.

This component requires [Safe Mode](/components/safe_mode/) to be configured.

<Image src="/images/safemode-ui.png" width={449} height={77} layout="constrained" alt="" />

```yaml
# Example configuration entry
switch:
  - platform: safe_mode
    name: "Living Room Restart (Safe Mode)"
```

## Configuration variables

- All options from [Switch](/components/switch#config-switch).
