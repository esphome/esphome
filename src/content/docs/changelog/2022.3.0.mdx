## Python 3.8 Minimum

This release sets the minimum Python version to 3.8. Please upgrade your local python if you are unable
to update further.

## Webserver

Thanks to [@wilberforce](https://github.com/wilberforce) for doing a massive bunch of work on giving new life to the frontend of
the [webserver](/components/web_server/).
